Build or edit a frontend slide deck for: $ARGUMENTS

Follow the workflow described in the frontend-slides skill:

1. Clarify scope (talk length, audience, framework preference) if not specified.
2. Scaffold a runnable project if one doesn't already exist, reusing an
   established framework (reveal.js, Slidev, Spectacle, etc.) rather than
   hand-rolling slide infrastructure.
3. Structure content one idea per slide, with a title slide and a
   closing/summary slide, using speaker notes for context that shouldn't
   appear on-screen.
4. Apply consistent theming and presentation-readable font sizes.
5. Start the dev server and preview the result before finishing, reporting
   the local URL to the user.
