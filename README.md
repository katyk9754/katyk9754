# frontend-slides

A [Claude Code plugin marketplace](https://code.claude.com/docs/en/plugin-marketplaces)
providing the **frontend-slides** plugin: a skill that helps build, edit, and present
web-based slide decks (reveal.js, Slidev, Spectacle, or plain HTML/CSS/JS) from an
outline or markdown notes.

## Install

```
/plugin marketplace add katyk9754/katyk9754
/plugin install frontend-slides@frontend-slides
```

## What's included

- **`frontend-slides` plugin** (`plugins/frontend-slides`) — adds a `frontend-slides`
  skill that Claude uses when you ask it to create or edit a presentation/slide deck.
