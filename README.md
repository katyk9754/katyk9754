# frontend-slides

A [Claude Code plugin marketplace](https://code.claude.com/docs/en/plugin-marketplaces)
providing the **frontend-slides** plugin: a zero-dependency HTML presentation
generator with safe style presets, a bold template library, PowerPoint
conversion, and an anti-"AI slop" design philosophy.

## Install

```
/plugin marketplace add katyk9754/katyk9754
/plugin install frontend-slides@frontend-slides
```

## What's included

- **`frontend-slides` plugin** (`plugins/frontend-slides`) — adds a
  `frontend-slides` skill that Claude uses when you ask it to create a
  presentation, convert a PPT/PPTX to web, or build slides for a talk.
